# Pasta de Imagens

## Estrutura

```
images/
├── hero/          # Imagens do banner principal
├── services/      # Ícones e imagens de serviços
└── veterinary/    # Fotos da veterinária
```

## Como Adicionar Imagens

### 1. **Hero Images** (`/hero/`)
Imagens para o banner principal:
- `banner-hero.jpg` — Veterinária com cachorro feliz
- `banner-alternate.jpg` — Cachorro em consultório

### 2. **Services Images** (`/services/`)
Ícones ou fotos de cada serviço:
- `vacina.jpg`
- `ultrassom.jpg`
- `higiene-oral.jpg`
- `tosa.jpg`
- `chip.jpg`

### 3. **Veterinary Images** (`/veterinary/`)
Fotos da Dra. Luiza:
- `luiza-profile.jpg` — Foto 400x400px (quadrada)
- `luiza-with-pet.jpg` — Foto profissional com animal

## Fontes Recomendadas (Grátis)

- **Unsplash** — unsplash.com (cc0, uso livre)
- **Pexels** — pexels.com (domínio público)
- **Pixabay** — pixabay.com (cc0)

## Dicas

✓ Use imagens de alta qualidade (min. 1200px de largura)
✓ Otimize os arquivos (use tinypng.com ou similar)
✓ Use formatos: JPG ou WebP
✓ Tamanho recomendado: < 200KB por imagem
